We got nothin so far...

The bot for Waffo's Discord server (catto beans) keeps logs.

Logging

  • These logs are saved on an hourly basis.
  • There is a limit of 24 logs (each being one hour)
  • The bot logs the following for a message to the bot (uses the bot's prefix):
    • The message content and message id.
    • The user's global name, the user's username, and user id.
    • The server name and server id.
    • The channel name and channel id.
  • Logs may not be deleted after 24 hours (yet). The oldest log file is deleted when a 25th file is created.
